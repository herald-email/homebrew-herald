# Herald Homebrew Tap

This tap installs Herald, a terminal email client and inbox cleanup tool.

```bash
brew tap herald-email/herald
brew install herald
```

The formula installs these commands:

- `herald`
- `herald-mcp-server`
- `herald-ssh-server`

Herald releases are currently beta builds. The formula uses immutable release
tarballs from `herald-email/herald-mail-app` and is updated by the Herald release
workflow.
